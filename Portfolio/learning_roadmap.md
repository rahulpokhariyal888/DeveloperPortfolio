## Semester 1 — Programming and Computer Science Foundations

**Learning Goals:**
- Learn C programming fundamentals, including variables, loops, functions, arrays and pointers.
- Understand basic computer science concepts.
- Develop problem-solving and logical thinking skills.
- Learn Linux commands, Git and GitHub.

- Git and GitHub

- HTML, CSS and JavaScript

**Learning Goals:**
- Learn Data Structures and Algorithms (DSA).
- Study arrays, linked lists, stacks, queues, trees and sorting algorithms.
- Understand Database Management Systems and SQL.
- Learn web development fundamentals.
- Improve Python programming skills.

**Tools:**
- C and Python
- MySQL
- Git and GitHub
- Visual Studio Code

**Milestone:** Complete one practical web or programming project and strengthen problem-solving skills.

**Certification Goal:** Complete one NPTEL or equivalent recognised online certification in Python programming or Data Science before the end of Semester 2.

## Semester 3 — AI and Machine Learning Foundations

**Learning Goals:**
- Study Python libraries such as NumPy, Pandas and Matplotlib.
- Learn statistics and probability for data science.
- Understand linear algebra fundamentals.

- Practise DSA regularly.

**Tools:** Python, Jupyter Notebook, NumPy, Pandas and Scikit-learn.

**Milestone:** Build a beginner machine learning project using a real dataset.

## Semester 4 — Applied Machine Learning

**Learning Goals:**
- Study supervised and unsupervised learning.
- Learn model evaluation and feature engineering.
- Understand data preprocessing.
- Explore computer vision fundamentals.

**Tools:** Python, Scikit-learn, OpenCV, FastAPI and GitHub.
